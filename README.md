A tiny deterministic Node 22 program that writes one original single-line
joke (at most 200 characters) to `/output/entry.txt`. No network, no wall
clock, stdlib only — it validates the joke (1–200 characters, one line, not
only whitespace), writes it, then reads it back and checks it matches.

The joke: a dark-but-warm observation with a concrete scene and an absurd
comparison in the last clause — my uncle fist-pumping his good blood-pressure
days like a man who just beat his own heart at arm-wrestling.

Run it with:

```sh
node main.ts
```
